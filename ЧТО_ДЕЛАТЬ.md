# Что делать по шагам (короткая версия)

## Шаг 1. Обновить файлы

В папке `F:\Visual Studio\VulkanProxy\INDIANA_AGENT`:

```
git pull
```

(или распаковать архив заново поверх)

**Удали старый лог, чтобы скрипт не прочитал его снова:**

```
del VulkanProxy_diagnostic.log
```

Если файла нет — ничего страшного.

## Шаг 2. Пересобрать DLL

```
powershell -ExecutionPolicy Bypass -File .\build_proxy.ps1
```

Ждём:

```
OK: every spvrw symbol used outside the namespace is qualified or forwarded
Assembling: vk_proxy_thunks.generated.asm
dllmain.cpp
Built: ...vulkan-1.dll
```

Если появилось `FAIL` вместо `OK` — пришли эту строку, сборку не продолжать.

## Шаг 3. Скопировать в игру

Скопировать в папку с игрой (туда, где уже лежит `vulkan-1.dll`):

- `vulkan-1.dll` — только что собранный
- `VulkanProxy.ini`
- папку `spv_replace` (целиком, 3 файла)

Проверить в `VulkanProxy.ini`:

```
UseReplacements=1
StructureMatchFallback=1
FuzzyMatch=1
SelfTest=0
```

## Шаг 4. Запустить игру

Дойти до игрового процесса, постоять 1–2 минуты, выйти через меню.

## Шаг 5. Прочитать лог **в папке игры**

```
cd /d "F:\Indiana.Jones.and.the.Great.Circle.Premium.Edition-InsaneRamZes"
findstr /C:"SPIRV SUMMARY:" VulkanProxy_diagnostic.log
```

Ищем таблицу:

```
SPIRV SUMMARY: per stage - stage | compiled | replaced | close-but-rejected | verdict
SPIRV SUMMARY:   fragment     |    444 |      0 |      0 | no file of this stage in the folder
SPIRV SUMMARY:   compute      |     22 |      3 |      0 | ok
```

**Как читать последнюю колонку:**

| Что видно | Что делать |
|---|---|
| `ok` | всё хорошо, замена работает |
| `no file of this stage in the folder` | нормально, для этой стадии файлов нет |
| **`ACTION: a file almost matched`** | **вот это интересно** — пришли мне лог |
| `nothing in this log was rejected by the thresholds` | делать нечего, папка исчерпана |

## Шаг 6 (только если в Шаге 5 было ACTION)

1. В `VulkanProxy.ini` поставить `DumpLookupInput=8`
2. Запустить игру на 1 минуту
3. В папке игры появятся файлы `spv_input_*.spv`
4. Запустить:
   ```
   spv_check.exe "F:\...\spv_replace" "F:\...\spv_input_5_42.spv"
   ```
5. Прислать мне строки `shape=... layout=...` и `=> WOULD MATCH` / `=> NO MATCH`

## Важно про сам скрипт проверки

`check_spv_replace.ps1` читает лог **из своей папки**. Раньше он находил старый лог в
папке сборки и делал по нему ложные выводы (писал «All lookups missed», хотя в реальном
логе игры было `3 accepted`).

Теперь скрипт:
- печатает путь к логу, его возраст и строку `=== VulkanProxy ...` из заголовка;
- предупреждает, если лог старше суток;
- умеет читать конкретный файл: `.\check_spv_replace.ps1 -Log "полный\путь\к\логу"`.

**Правильный запуск — из папки игры:**

```
cd /d "F:\Indiana.Jones.and.the.Great.Circle.Premium.Edition-InsaneRamZes"
powershell -ExecutionPolicy Bypass -File "F:\Visual Studio\VulkanProxy\INDIANA_AGENT\check_spv_replace.ps1"
```
